# Calculator skins

The SVG files in `public/skins/` are vendored generated artifacts from
`zyf722/hp-calcs-svg`, artifact commit
`8720fb9d63c60916819efd2dae4b28ef7c01e8d9`.

webemu48 uses the outlined variants so the browser does not depend on local
font installation. The source project is Apache-2.0 licensed.

These vectors replace the original Emu48 Android bitmap skins in the web UI.
KML remains in the emulator core for button geometry and machine configuration.
